# ООО «ФЕДСТРОЙ» — Вентилируемые фасады, фальшполы и подсистемы

Современный, быстрый и адаптивный B2B-лендинг строительной компании **ООО «ФЕДСТРОЙ»** (г. Москва / г. Кострома).

## 🚀 Особенности проекта

- **Чистый стек без тяжелых зависимостей**: HTML5 + Tailwind CSS + Vanilla JS.
- **Широкоформатная адаптивность**: плавная поддержка любых экранов от смартфонов до 27"–32" QHD и 4K-мониторов.
- **Интерактивный B2B-калькулятор стоимости**: динамический расчет сметной вилки цен, стоимости за м² и сроков производства/монтажа в зависимости от площади, облицовочного материала (керамогранит, композит, металлокассеты, сульфат кальция, ДСП) и металла несущей подсистемы (оцинковка, алюминий, нержавейка).
- **Реальная фотогалерея объектов с Lightbox**: полноэкранный просмотр 12 реальных объектов компании (фасады ТЦ, жилые комплексы, серверные ЦОД, офисные пространства) с фильтрацией по категориям.

## 📦 Структура файлов

- `index.html` — основная страница сайта с семантической структурой и секциями
- `app.js` — логика калькулятора, модальных окон, лайтбокса и валидации форм
- `styles.css` — адаптивная контейнерная сетка и стилизация элементов управления

## 🌐 Локальный запуск

Просто откройте `index.html` двойным кликом в любом современном браузере.
Или запустите любой локальный HTTP-сервер:

```bash
# Python
python -m http.server 8080

# Node.js
npx serve
```
