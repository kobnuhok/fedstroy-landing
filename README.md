## 🚀 Архитектура и модульное разделение

Проект разделен на независимые компоненты, стили и отказоустойчивые скрипты. Любой блок можно удалить или закомментировать в `src/template.html`, и сайт пересоберется без ошибок:

```

│   ├── header.html             # Верхняя плашка, меню, телефон 8 (800)
│   ├── hero.html               # Главный экран с формой расчета и фактами
│   ├── about.html              # О компании, реквизиты, 10+ лет опыта
│   ├── services.html           # 6 основных направлений работ
│   ├── quiz.html               # 5-шаговый интерактивный квиз с авто-сметой
│   ├── calculator.html         # Инженерный онлайн-калькулятор стоимости
│   ├── systems.html            # Сравнение подсистем (сталь, алюминий, нержавейка)
│   ├── portfolio.html          # Фильтр объектов и 12 фото реализованных объектов
│   ├── compliance.html         # СРО, ГОСТы, пожарные сертификаты К0

│   └── modals.html             # Модальные окна (заявка, быстрый звонок, фото-лайтбокс)
├── css/
│   ├── style.css               # Базовые стили: кнопки, карточки, слайдер, модалки
│   └── adaptive.css            # Адаптивная верстка (мобильные, планшеты, 27" QHD, 4K)
├── js/
│   ├── main.js                 # Главная точка входа (ES modules)
│   └── modules/                # Изолированные отказоустойчивые модули
│       ├── navigation.js       # Мобильное меню и якорные переходы

├── package.json                # npm scripts
├── index.html                  # Готовый скомпилированный production-файл
├── styles.css                  # Импорт базовых и адаптивных стилей
└── app.js                      # Скомпилированный production JS-бандл
```

## 🛠 Команды разработки

```bash
# 1. Быстрая сборка проекта (занимает ~10 мс)
npm run build
# или
node build.js

# 2. Режим отслеживания изменений (авто-пересборка при сохранении любого файла)
npm run dev
# или
node build.js --watch

# 3. Локальный веб-сервер
npm run serve
```

## 🧩 Как убрать или добавить блок

1. Откройте `src/template.html`.
2. Закомментируйте или удалите ненужный блок, например:
   ```html
   <!-- @@include blocks/quiz.html -->
   ```
3. Запустите сборку `npm run build` (или при `npm run dev` пересборка произойдет мгновенно сама).
4. **Готово!** Блок удален из `index.html`. В браузере не будет никаких ошибок `null is not an object` — скрипты автоматически обнаружат отсутствие блока и продолжат штатно работать.
